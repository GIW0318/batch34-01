# GSB Bugfix Task
## 题面
开黑组队界面改版后，队伍配置经常卡住：同一个玩家能重复进队，队伍已经满员还能继续邀请，两个坦克同时进队也不提示，评分填 0 或者填字符串也能保存，把坦克换成治疗时提示没有名额，平均分算出来不带小数，人数不够或者缺治疗时准备按钮却是亮的。team_roster.py 的 TeamRoster 负责 add、remove、swap、average_rating、ready 和 state。实现要限制职业只能取 tank、healer、dps，每个职业有人数上限，评分取 1 到 5000 的整数，玩家不能重复且不能超过队伍容量；换职业按新职业剩余名额校验，换回自己原职业要拒绝；平均分保留两位小数并拒绝空队伍；只有满员且至少各有一名坦克和治疗时 ready 才为 True；state 返回的成员快照不能被外部改动。

## 运行方式
```bash
python -m pytest tests -q
```
