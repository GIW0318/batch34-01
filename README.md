# GSB Bugfix Task
## 题面
宠物训练改成客户端记冷却后，面板数值开始漂移：同一次训练连点两下属性加两次，冷却没走完还能继续练，体力扣了属性却没涨，经验攒够却不升级，进化只换名字不换属性，进化后还能再进化一次，离线期间冷却没有跟着时间推进。训练只能作用于已创建的宠物，属性名必须出现在物种初始属性里；升级只改等级和经验，不自动回满体力；进化不消耗体力，进化后保留当前冷却，没有进化形态的物种不能进化。pet_training.py 的 PetTrainer 负责 create_pet、train、evolve 和 status。创建时按物种表写入初始属性与 100 点体力；每次训练消耗 10 点体力、增加 25 点经验并进入 30 秒冷却，升级所需经验为当前等级乘 100，升级后多余经验保留；冷却未结束或体力不够时训练抛 ValueError，进化要求等级至少 2 且不在冷却中，进化后阶段、名称和属性一起变化且只能进行一次；未知物种、未知属性、非正数量和重复进化同样抛 ValueError。

## 运行方式
```bash
python -m pytest tests -q
```
