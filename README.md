# GSB Bugfix Task
## 题面
副本锁定乱成一锅粥：打完普通难度英雄难度跟着锁死；锁定没到期居然放行；跨周不重置；手动清锁只清一个难度；剩余时间还能算出负数。raid_lockout.py 的 RaidLockout 要补齐进本登记、是否可进、剩余秒数、清锁和取快照：进本按玩家、副本、难度三个维度登记，时长读构造参数里的难度表，零秒表示不锁；锁定期间再进要报 ValueError；到期那一刻起放行；可进时剩余秒数返回零；难度之间互不影响；跨过周期边界旧锁定自动作废；清锁传玩家只清那个人，不传就清全部，清一个没记录的人要报错；时间戳不能为负，未知难度也要报 ValueError。周期编号用时间戳整除周期长度得到，跨过边界就视为新的一周；同一玩家打不同副本互不干扰；清锁只影响锁定，历史击杀次数保留。登记时先查表再写记录，未知难度不能落账，剩余秒数不能出现负值；清锁之后可以重新进本。快照独立于内部结构。

```bash
python -m pytest tests -q
```
