# GSB Bugfix Task
## 题面
排行榜一开赛季，名次就开始乱：同分玩家按提交顺序排，后提交的反而压前面；旧赛季的分数没有清掉，新赛季榜单里还能看到；玩家重复提交低分把最高分覆盖；并列时没有稳定次序；取前 N 名越界不报错。leaderboard_ties.py 的 Leaderboard 负责 submit、top、reset 和 state。实现要只保留每个玩家的最高分、同分按最早达到时间和玩家 id 排序、赛季切换清空旧榜、top 的 N 必须是正整数且不超过容量、重复玩家只更新最高分；分数类型不对、名次越界或赛季参数非法时直接报错。

## 运行方式
```bash
python -m pytest tests -q
```
