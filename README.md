# GSB Bugfix Task
## 题面
通行证最近漏得厉害：玩家经验都攒到一百二十了，界面还显示零级；同一档奖励被反复领取；没解锁的档位也能点；换季之后经验清空，可上一季的进度却查不到了。battle_pass.py 里的 BattlePass 要按用例补齐入会、加经验、查看档位、领奖、查赛季、切换赛季和取快照这些入口：经验封顶在最后一档，重复入会、空白名字、给没入会的人加经验、加零或负数、领没解锁或已经领过的档位都必须报 ValueError，领奖返回档位序号和对应金币数。切换赛季时旧数据归档到 archives 下，新赛季所有人的经验与领取记录清零，赛季名跟当前一样或者为空要报错。已领档位按序号从小到大排好；加经验先校验再落账，失败不能留下半截状态。换季不是把数据抹掉，而是搬进归档区，方便客服回查上一季的最终档位和已领清单。快照返回的对象跟内部数据隔离，外部改动不能回写。现有 pytest 跑下来一条都过不了。

## 运行方式
```bash
python -m pytest tests -q
```
