# GSB Bugfix Task
## 题面
录像回看功能上线后，战队分析师抱怨书签不可用：同一段录像里给同一秒打两次标记，列表出现两条重复；时间轴可以填负数，也能超过录像总时长，播放器跳转直接黑屏；标记只有创建者能看到，分享给队友后对方刷新还是空的；队友把别人分享的标记删掉，原作者再也找不到自己的标注；录像过了保留期被清理，书签却还挂在列表里，点开全部失效；导出状态时改动返回值，会把内存里的原始数据一起改坏。replay_bookmark.py 的 ReplayBookmarks 负责 add、remove、share、visible、prune 和 state。标记编号唯一，同一玩家同一时间点只允许一条；只有作者能删除或分享，分享可重复调用但不产生副本；可见列表按时间排序并带作者信息；保留期从创建时间起算，prune 清理超期标记并返回编号；参数不合法用 ValueError 拒绝，权限不足按权限异常处理。

## 运行方式
```bash
python -m pytest tests -q
```
