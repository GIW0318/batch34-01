# GSB Bugfix Task
## 题面
赛季结算发奖没人敢碰：名次对应的档位算错；第一名拿到了末档奖励；超出范围不报错反而给空奖；同一个人能领两次；结束后还能补录；宽限期过了也查不出谁没领。season_reward.py 的 SeasonReward 要补齐登记名次、查档位奖励、领奖、查过期未领和取快照：档位从第一名开始，首尾相接不重叠；登记名次必须早于赛季结束时刻；重复登记直接报 ValueError；奖励按登记时的名次固定下来；领取只允许一次，截止时刻是赛季结束加宽限，边界当天仍可领，过了拒绝；查档位返回金币和起止名次；过期未领名单按名字排序。构造时档位不从第一名起或有重叠要报错。档位按名次区间查表，区间两端的名次都算在档内；重复提交不能覆盖第一次登记的名次和奖励；过期名单只统计已经登记却没领的人，没登记的玩家不出现。领取成功后状态里要能看出已经领过；档位区间不能有缺口。仓库用例全红。

## 运行方式
```bash
python -m pytest tests -q
```
