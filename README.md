# GSB Bugfix Task
## 题面
赛事系统开放观战后，导播台频繁翻车：观战位上限设成 2，第三个人还是挤了进来，把正在解说的人顶掉；退出观战后席位没有释放，新观众一直排队；普通观众能直接看到实时画面，比场上选手还快，延迟参数形同虚设；裁判和解说没有办法获得无延迟视角；任何人都能修改别人的观战身份，也能把房主请出去；被请离的观众换个入口又能回来。spectator_slots.py 的 SpectatorSlots 实现 open_match、join、leave、set_role、visible、kick 和 state。每个房间按容量分配席位，重复加入不额外占位，退出立即释放；普通观众按配置延迟看到事件，裁判身份不受延迟限制；只有房主能调整身份或请离观众，被请离者不得再次进入；房间不存在、身份非法或重复开房都按参数错误处理，越权行为按权限异常处理。

## 运行方式
```bash
python -m pytest tests -q
```
